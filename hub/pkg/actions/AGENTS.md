## Members

- `app.go`, `app_test.go`, `app_postgres_integration_test.go`: implement and verify the complete native Fiber application beneath the public Hub Runtime, isolated foreground/background PostgreSQL Catalog pools, River or synchronous task runtime, periodic business tasks, PostgreSQL boot/restart with queued-job recovery, middleware lifecycle, and injectable community-data wiring.
- `background_tasks.go`, `background_tasks_test.go`: define and verify first-class River JobArgs, stable observable kinds, payload validation, Repository metadata and Package latest sweep/worker boundaries, dispatcher versus source or single-localization timeout behavior, and domain-handler adapters.
- `package_latest_sync.go`, `package_latest_sync_test.go`: periodically keyset-scan discovery-visible Packages or accept one manual Package check, resolve upstream `latest` without scanning Skill trees, skip exact observed identities, reject moved immutable Versions, and publish only newly resolved exact Versions through the ordinary Package Publisher.
- `package_update_check.go`, `package_update_check_test.go`: expose and verify the strict public single-Package update-check request, returning either an already-current immutable Version or a newly queued exact Version.
- `translation_jobs.go`, `translation_jobs_test.go`: register and verify description/document translation dispatch, shared payment-failure circuit breaking, item execution, retry-aware failure finalization, and River-native periodic scheduling for reusable composition.
- `app_proxy.go`, `app_proxy_test.go`: compose source discovery, Artifact Store, Catalog, automatic Package latest synchronization, OpenAPI, Package metadata, and Skill-content routes through Fiber and cover integration behavior.
- `basicauth.go`, `basicauth_test.go`, `admin_auth_test.go`: configure global versus administration-scoped HTTP Basic Auth behavior; source publication remains credential-free while GitHub tokens are metadata-API-only.
- `catalog_api.go`, `catalog_api_test.go`: expose `GET /api/v1/skills/find` with zero-based page/per-page requests, greedy one-extra-row has-more responses, source-pinned GitHub README presentation URLs, and set-based language-localized current or immutable Package card reads; ordinary search remains current-Catalog-only. They also own candidate Find, exact-path ordered batch-card hydration, set-based Catalog-only Package update checks, and correlated private diagnostics without request-driven metadata maintenance.
- `community_api.go`: owns strict, always-present installation-event and ranking routes over an injected persistent or empty self-host community-data implementation.
- `openapi.go`, `api_operations.go`, `api_examples.go`, `openapi_test.go`, `assets/`: use Huma as a typed OpenAPI 3.1 projection over native Fiber handlers, derive non-cacheable component schemas from Hub and Protocol DTOs, provide coherent real-world mattpocock/skills examples, guard product-route coverage, serve a self-hosted Scalar reference with compressed immutable assets, honor deployment prefixes, and prevent legacy route names from returning to the document.
- `skill_card_projection.go`, `skill_card_projection_test.go`: adapt final Catalog read rows to the reusable `pkg/skillcard` projection and verify ordered cardinality behavior; the adapter cannot access task queues or source providers.
- `catalog_postgres_integration_test.go`: verifies pagination and empty discovery response parity through the same HTTP router against PostgreSQL.
- `package_protocol.go`, `package_protocol_test.go`: merge Catalog publication history with source Tags, resolve `latest` from the highest-priority effective Version currently known to the Catalog, serve Catalog-built Package Info with static Git Artifact Repository URLs, trigger exact cold publication, and reject nested Skill artifact coordinates.
- `package_skill.go`: serves one exact Skill path under a canonical Package Version, resolves movable queries to immutable versions, and independently overlays localized description and display-document projections when `lang` is present.
- `package_publisher.go`: validates complete Package Artifacts, pins automatic latest publication to its previously resolved expected commit, computes description/document digests and source language once at publication, prepares typed immutable Package Info plus content-addressed Skill source objects, coordinates bounded and negative-cached Source Repository work, and batches Backfill Publications by consuming one explicitly leased Skill-source Backfill session plus one Artifact session while retaining ordinary single-Version publication.
- `package_publication_commit.go`, `package_publication_commit_test.go`: own retry-safe Git Repository then content-addressed Skill-source residency followed by independently atomic Catalog visibility, using one advisory-lock connection and one hydration for bounded Backfill generations while retaining failed-publication orphans for later residency GC.
- `package_publication_failure.go`: defines stable non-sensitive Publication Failure Codes across snapshot validation, Git authoring, storage replication, Skill-content persistence, and Catalog commit stages.
- `module_version_query.go`, `module_version_query_test.go`: resolve typed movable Version Queries once into immutable Package Version Records through the Package-scoped query API.
- `package_backfill.go`, `package_backfill_test.go`: validate and expose bounded `/api/v1/admin/package-backfills` batches, persist one independent Run per Package, prepare and close one leased source session per River job, preserve the highest-twenty Revision selection even when a Revision contains no Skills, execute the selected Tags or default-branch pseudo-versions through one chunked Publisher session, persist explicit per-Version outcomes, and retry only transient failures.
- `repository_metadata.go`, `repository_metadata_test.go`: maintain Repository About descriptions and popularity metadata exclusively through publication-triggered unique refresh jobs and an ID-keyset periodic stale-Package sweep, sharing TTL/ETag/Singleflight/backoff state while implementing sticky GitHub-token failover and safe diagnostics outside public read paths.
- `health.go`, `readiness.go`: expose service health and readiness probes.
- `info.go`: exposes optional public client capabilities, including a configured image-proxy Origin, without leaking deployment internals.
- `home.go`, `robots.go`, `version.go`: serve the human landing, crawler policy, and service version surfaces.
- `storage.go`, `storage_test.go`: wire artifact storage providers into the service, including first-class Cloudflare R2 configuration through the shared S3-compatible backend.

## Architectural Boundary

This module owns native Fiber HTTP/service composition and stable public protocol serialization. Shared wire DTOs belong to `/protocol/api`; this module delegates metadata behavior to `pkg/catalog`, immutable artifacts to Protocol/storage packages, and configuration to `pkg/config`. It must not duplicate their domain logic, expose database-specific response shapes, or introduce standard-library handler adapters inside the application request path.
