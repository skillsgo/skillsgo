# Name the Public Distribution Context SkillsGo Hub

SkillsGo names its public Skill discovery and distribution product, domain context, workspace, executable, configuration namespace, and client vocabulary **SkillsGo Hub**. “Registry” was technically accurate but sat at a different abstraction level from SkillsGo App; Hub provides one product name for Skill identity, search, immutable artifacts, trust metadata, distribution, and the complete public route surface while preserving existing Skill coordinates and sums.
