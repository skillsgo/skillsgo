SkillsGo منظومة مفتوحة لاكتشاف Agent Skills وإدارتها. يوفّر App سطح المكتب للأشخاص مسارًا مرئيًا لاكتشاف Skills وإدارتها، بينما يربط CLI كتالوج Hub نفسه بمسارات CI/CD وبيئات العمل القابلة لإعادة الإنتاج.

## شاهد SkillsGo أثناء العمل

## لماذا SkillsGo

- **أدلة حقيقية من المصدر** — افحص هوية المستودع والإصدار و`SKILL.md` والملفات والمخاطر قبل التثبيت.
- **وجهات Agent صريحة** — ثبّت Skills بصورة عامة أو ضمن مشروع لدى Agents المحددة بدلًا من نسخ الملفات يدويًا.
- **توزيع قابل للتحقق** — تعامل مع إصدار مستودع المصدر بوصفه وحدة توزيع غير قابلة للتغيير.
- **إدارة محلية أولًا** — افحص المخزون المحلي وأدره بأمان حتى عندما لا يكون Hub متاحًا.
- **واجهتان مصممتان لغرضين** — استخدم App لمسارات العمل الشخصية التفاعلية، وCLI في CI/CD والأتمتة وبيئات Skill المتسقة.

## آلية العمل

<p align="center">
  <img src="../../assets/readme/workflow.svg" width="100%" alt="مسار SkillsGo: الاكتشاف والتحقق واختيار الوجهات والتثبيت والإدارة">
</p>

يمثل Hub العام المصدر المشترك لهوية Skills والإصدارات غير القابلة للتغيير والبيانات الوصفية والبحث والاكتشاف. يربط App الأشخاص بـ Hub من خلال مسار مرئي، بينما يربط CLI الأتمتة وCI/CD بـ Hub نفسه للحفاظ على اتساق اختيارات Skills بين البيئات.

## استكشف monorepo

```text
skillsgo/
├── app/       Flutter desktop client and user experience
├── cli/       Go CLI and local Skill execution engine
├── hub/       Public Skill Hub service and reusable runtime
├── protocol/  Shared executable contracts used by CLI and Hub
├── web/       Public product, Hub, and documentation surface
└── e2e/       Cross-product CLI/Hub and desktop journeys
```

راجع [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md) للتعرف على حدود المنتج ومصطلحات المجال.

## التشغيل محليًا

تستهدف بيئة التطوير الموحدة حاليًا macOS وتتطلب Flutter وGo وDocker و[Process Compose](https://github.com/F1bonacc1/process-compose) و[Air](https://github.com/air-verse/air).

```bash
make dev
```

يشغّل هذا الأمر PostgreSQL وHub المحلي وCLI مبنيًا حديثًا وApp سطح المكتب المبني باستخدام Flutter ضمن جلسة واحدة خاضعة للإشراف. للتحقق من جميع مساحات العمل المهيأة:

```bash
make test
```

تتوفر أيضًا نقطة دخول منفصلة لكل مساحة عمل:

| مساحة العمل | التطوير أو التحقق |
| --- | --- |
| App | `cd app && flutter run -d macos` |
| CLI | `cd cli && go test ./...` |
| Hub | `cd hub && go test ./...` |
| Protocol | `cd protocol && go test ./...` |
| Web | `cd web && pnpm install && pnpm dev` |

راجع [CONTRIBUTING.md](../../CONTRIBUTING.md) قبل تغيير سلوك المنتج.

## حالة المشروع

يستعد SkillsGo لإصداراته الأولى. يُحدَّد مسار إصدار Hub أولًا، بينما تخضع إصدارات App الموقعة والموثقة وتوزيع CLI المستقل لمعايير جاهزية خاصة بها. راجع [تصميم الإصدار](../release-design.md) لمعرفة وحدات الإصدار المدعومة وسلامة العناصر ومتطلبات سلسلة التوريد.
