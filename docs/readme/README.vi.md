SkillsGo là một hệ sinh thái mở để khám phá và quản lý Agent Skills. App dành cho máy tính mang đến cho người dùng một cách trực quan để khám phá và quản lý Skills, còn CLI đưa cùng danh mục Hub vào CI/CD và các quy trình môi trường có thể tái tạo.

## Xem SkillsGo hoạt động

App dành cho máy tính kết nối việc khám phá, bằng chứng nguồn, đích cài đặt và kho cục bộ thành một hành trình dễ hiểu. Người dùng cá nhân không cần tài khoản.

## Vì sao nên dùng SkillsGo

- **Bằng chứng nguồn thực tế** — kiểm tra danh tính kho, phiên bản, `SKILL.md`, tệp và rủi ro trước khi cài đặt.
- **Đích Agent rõ ràng** — cài đặt Skills trên toàn hệ thống hoặc theo phạm vi dự án cho các Agents đã chọn mà không phải sao chép tệp thủ công.
- **Phân phối có thể xác minh** — coi một bản phát hành của kho nguồn là đơn vị phân phối bất biến.
- **Ưu tiên quản lý cục bộ** — kiểm tra và quản lý kho cục bộ một cách an toàn ngay cả khi Hub không khả dụng.
- **Hai giao diện chuyên biệt** — dùng App cho quy trình cá nhân tương tác và CLI cho CI/CD, tự động hóa cùng các môi trường Skill nhất quán.

## Cách hoạt động

<p align="center">
  <img src="../../assets/readme/workflow.svg" width="100%" alt="Quy trình SkillsGo: khám phá, kiểm tra, chọn đích, cài đặt và quản lý">
</p>

Hub công khai là nguồn dùng chung cho danh tính Skills, các bản phát hành bất biến, siêu dữ liệu, tìm kiếm và khám phá. App kết nối người dùng với Hub bằng quy trình trực quan; CLI kết nối tự động hóa và CI/CD với cùng Hub để lựa chọn Skills luôn nhất quán giữa các môi trường.

## Khám phá monorepo

```text
skillsgo/
├── app/       Flutter desktop client and user experience
├── cli/       Go CLI and local Skill execution engine
├── hub/       Public Skill Hub service and reusable runtime
├── protocol/  Shared executable contracts used by CLI and Hub
├── web/       Public product, Hub, and documentation surface
└── e2e/       Cross-product CLI/Hub and desktop journeys
```

Đọc [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md) để biết ranh giới sản phẩm và ngôn ngữ miền.

## Chạy cục bộ

Cấu trúc phát triển hợp nhất hiện nhắm đến macOS và yêu cầu Flutter, Go, Docker, [Process Compose](https://github.com/F1bonacc1/process-compose) cùng [Air](https://github.com/air-verse/air).

```bash
make dev
```

Lệnh này khởi động PostgreSQL, Hub cục bộ, CLI vừa được xây dựng và App Flutter dành cho máy tính trong một phiên được giám sát. Để xác thực mọi workspace đã cấu hình:

```bash
make test
```

Mỗi workspace cũng có một điểm vào riêng:

| Workspace | Phát triển hoặc xác thực |
| --- | --- |
| App | `cd app && flutter run -d macos` |
| CLI | `cd cli && go test ./...` |
| Hub | `cd hub && go test ./...` |
| Protocol | `cd protocol && go test ./...` |
| Web | `cd web && pnpm install && pnpm dev` |

Đọc [CONTRIBUTING.md](../../CONTRIBUTING.md) trước khi thay đổi hành vi sản phẩm.

## Trạng thái dự án

SkillsGo đang chuẩn bị các bản phát hành đầu tiên. Quy trình phát hành Hub được xác định trước; các bản phát hành App đã ký và công chứng cùng bản phân phối CLI độc lập tuân theo tiêu chí sẵn sàng riêng. Xem [thiết kế phát hành](../release-design.md) để biết các đơn vị phát hành được hỗ trợ, tính toàn vẹn của tạo phẩm và yêu cầu chuỗi cung ứng.
