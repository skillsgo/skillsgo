SkillsGo, Agent Skills खोजने और प्रबंधित करने के लिए एक खुला पारिस्थितिकी तंत्र है। डेस्कटॉप App लोगों को Skills खोजने और प्रबंधित करने का दृश्य तरीका देता है, जबकि CLI उसी Hub कैटलॉग को CI/CD और दोहराए जा सकने वाले परिवेश कार्यप्रवाहों से जोड़ता है।

> [!IMPORTANT]
> SkillsGo अपनी पहली स्थिर रिलीज़ से पहले सक्रिय विकास में है। सार्वजनिक प्रोटोकॉल, स्थायी प्रारूप और इंस्टॉलेशन व्यवहार बदल सकते हैं।

## SkillsGo को काम करते देखें

<p align="center">
  <img src="../../assets/readme/discover-ranking.png" width="100%" alt="SkillsGo डेस्कटॉप App सार्वजनिक Hub की लाइव रैंकिंग से Agent Skills दिखाता है">

डेस्कटॉप App खोज, स्रोत प्रमाण, इंस्टॉलेशन लक्ष्य और स्थानीय इन्वेंटरी को एक सरल यात्रा में जोड़ता है। व्यक्तिगत उपयोग के लिए खाते की आवश्यकता नहीं है।

### Hub से खोजें

Skill या स्रोत रिपॉज़िटरी के आधार पर खोजें, लाइव रैंकिंग देखें और एक Skill या पूरा संग्रह इंस्टॉल करें।

## SkillsGo क्यों

- **वास्तविक स्रोत प्रमाण** — इंस्टॉलेशन से पहले रिपॉज़िटरी की पहचान, संस्करण, `SKILL.md`, फ़ाइलें और जोखिम जाँचें।
- **स्पष्ट Agent लक्ष्य** — फ़ाइलें हाथ से कॉपी करने के बजाय चुने हुए Agents के लिए वैश्विक या प्रोजेक्ट दायरे में Skills इंस्टॉल करें।
- **सत्यापन योग्य वितरण** — स्रोत रिपॉज़िटरी की रिलीज़ को अपरिवर्तनीय वितरण इकाई मानें।
- **स्थानीय-प्रथम प्रबंधन** — Hub अनुपलब्ध होने पर भी स्थानीय इन्वेंटरी की सुरक्षित जाँच और प्रबंधन करें।
- **दो उद्देश्य-विशिष्ट इंटरफ़ेस** — व्यक्तिगत संवादात्मक कार्यप्रवाहों के लिए App और CI/CD, स्वचालन तथा सुसंगत Skill परिवेशों के लिए CLI का उपयोग करें।

## यह कैसे काम करता है

<p align="center">
  <img src="../../assets/readme/workflow.svg" width="100%" alt="SkillsGo कार्यप्रवाह: खोजें, जाँचें, लक्ष्य चुनें, इंस्टॉल करें और प्रबंधित करें">
</p>

सार्वजनिक Hub, Skill पहचान, अपरिवर्तनीय रिलीज़, मेटाडेटा, खोज और अन्वेषण का साझा स्रोत है। App दृश्य कार्यप्रवाह के माध्यम से लोगों को Hub से जोड़ता है; CLI स्वचालन और CI/CD को उसी Hub से जोड़ता है ताकि विभिन्न परिवेशों में Skill चयन सुसंगत रहे।

## monorepo देखें

```text
skillsgo/
├── app/       Flutter desktop client and user experience
├── cli/       Go CLI and local Skill execution engine
├── hub/       Public Skill Hub service and reusable runtime
├── protocol/  Shared executable contracts used by CLI and Hub
├── web/       Public product, Hub, and documentation surface
└── e2e/       Cross-product CLI/Hub and desktop journeys
```

उत्पाद सीमाओं और डोमेन भाषा के लिए [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md) पढ़ें।

## स्थानीय रूप से चलाएँ

एकीकृत विकास व्यवस्था वर्तमान में macOS को लक्षित करती है और इसके लिए Flutter, Go, Docker, [Process Compose](https://github.com/F1bonacc1/process-compose) तथा [Air](https://github.com/air-verse/air) आवश्यक हैं।

```bash
make dev
```

यह कमांड PostgreSQL, स्थानीय Hub, नया बनाया गया CLI और Flutter डेस्कटॉप App एक ही पर्यवेक्षित सत्र में शुरू करता है। सभी कॉन्फ़िगर किए गए वर्कस्पेस सत्यापित करने के लिए:

```bash
make test
```

प्रत्येक वर्कस्पेस का अपना प्रवेश बिंदु भी उपलब्ध है:

| वर्कस्पेस | विकास या सत्यापन |
| --- | --- |
| App | `cd app && flutter run -d macos` |
| CLI | `cd cli && go test ./...` |
| Hub | `cd hub && go test ./...` |
| Protocol | `cd protocol && go test ./...` |
| Web | `cd web && pnpm install && pnpm dev` |

उत्पाद व्यवहार बदलने से पहले [CONTRIBUTING.md](../../CONTRIBUTING.md) पढ़ें।

## प्रोजेक्ट की स्थिति

SkillsGo अपनी पहली रिलीज़ की तैयारी कर रहा है। Hub रिलीज़ पाइपलाइन पहले परिभाषित होती है; हस्ताक्षरित और नोटरीकृत App रिलीज़ तथा स्वतंत्र CLI वितरण अपनी अलग तैयारी शर्तों का पालन करते हैं। समर्थित रिलीज़ इकाइयों, आर्टिफ़ैक्ट अखंडता और आपूर्ति शृंखला आवश्यकताओं के लिए [रिलीज़ डिज़ाइन](../release-design.md) देखें।
